在唯一的亲人祖母过世之后，孤独的男主角飞鸟凑遇到了同样年纪但在经营女子学校的西园寺风莉。在西园寺风莉的带领下，飞鸟凑穿上了女生的制服，入读白铃女子学园并住进了女生宿舍。\
\
**飞鸟凑** （飛鳥 湊／あすか みなと） 声：歩サラ\
\
本作男主角，白铃女子学园二年级学生，在唯一的亲人祖母过世后被风莉收养。文武双全，家务万能，在凑与风莉等人居住的第二宿舍中包办了所有家务事，也因此在学园新闻部的票选中成为了“全校最适合当妻子的人选”第一名。\
\
生日：5月22日（双子座）　血型：O型　身高：158cm\
\
\
**西园寺风莉** （西園寺 風莉／さいおんじ かざり） 声：杏花\
\
白铃女子学园的理事长，财阀的大小姐，凑的同学，表面上是优等生，实际上并不擅长学习，自理能力极差。因小时候受到过当时家中女仆——凑的祖母照顾而收养了凑。与凑住在宿舍的同一个房间内。\
\
生日：12月7日（射手座）　血型：A型　身高：155cm　三围：B79/W58/H82\
\
\
**贵船柚子** （貴船 柚子／きふね ゆず） 声：上田朱音\
\
凑的同学，新闻部的部长。不擅长做家务，“黑暗料理”制作者，非常喜欢有浓厚味道的发酵食品。与凑、风莉住在同一宿舍。\
\
生日 : 4月3日（牡羊座）　血型：O型　身高：162cm　三围：B94/W60/H86\
\
\
**大垣日向**（大垣 ひなた／おおがき ひなた），声：姫川あいり\
\
白铃女子学园一年级学生，学园图书馆委员。自称为东方将军，魔王军四天王之一。经常会做出中二病的言行举止，但其实个性非常乖巧，做错事被训斥时会老实的向别人道歉。是个看似豪爽，但是却非常在意别人对她的看法的人。\
\
生日 : 2月4日（水瓶座）　血型：AB型　身高：148cm　三围：B84/W56/H80\
